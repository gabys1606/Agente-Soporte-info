Política de Privacidad

Agente de Soporte IA

Última actualización: 27 de octubre de 2026

1. Responsable del proyecto

Esta aplicación forma parte de un proyecto escolar de automatización con inteligencia artificial. Su uso está destinado al alumno que administra el proyecto con su propia cuenta de Google.

2. Datos a los que accede

El agente accede a la hoja de cálculo de Google Sheets asociada al proyecto. Lee el nombre del cliente y el comentario de cada respuesta para realizar el análisis solicitado.

También escribe en la misma hoja la clasificación, el sentimiento y una marca que indica si el registro fue procesado.

3. Cómo se utilizan los datos

El texto de cada comentario se envía a la API de Google Gemini para identificar su categoría y sentimiento. Los resultados del análisis se guardan en la hoja de cálculo original.

Las categorías utilizadas son Ventas, Soporte Técnico y Logística. Los sentimientos posibles son Positivo, Negativo y Neutro.

4. Almacenamiento y divulgación

El agente guarda los resultados en la hoja de cálculo original del proyecto. El código de la aplicación no está diseñado para guardar una copia de las quejas en otro servidor propio.

El tratamiento del contenido enviado a Google Gemini también está sujeto a las políticas y condiciones del servicio de Google.

5. Servicios de Google utilizados

El proyecto utiliza Google Forms, Google Sheets y la API de Google Gemini. La autenticación se realiza mediante los mecanismos de autorización de Google.

El uso de estos servicios está sujeto a las políticas aplicables de Google, incluida su política sobre datos de usuario de las API de Google.

6. Revocación del acceso

El usuario puede revisar y revocar el acceso concedido a las aplicaciones desde la configuración de su cuenta de Google.

Revisar los permisos de la cuenta de Google

7. Contacto

Para consultas sobre este proyecto escolar, se puede contactar al alumno responsable mediante el correo electrónico que proporcione para este fin.
